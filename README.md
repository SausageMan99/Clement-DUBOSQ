# Clément Dubosq — Portfolio

Personal portfolio & CV website built with Next.js, Tailwind CSS, and Framer Motion.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Push to GitHub
2. Import on [vercel.com](https://vercel.com)
3. Deploy — zero config needed

## Stack

- **Next.js 15** (App Router)
- **Tailwind CSS 4**
- **Framer Motion**
- **Lucide React**
- **TypeScript**

## Customization

- Replace `public/cv.pdf` with your actual CV
- Replace the photo placeholder in `About.tsx` with your image
- Update `public/og-image.png` with your OG image
